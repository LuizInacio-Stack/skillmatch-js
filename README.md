# SkillMatch JS

## Sobre o projeto

O SkillMatch JS é um simulador de compatibilidade entre um candidato e vagas de front-end júnior.

O projeto compara as habilidades do candidato com os requisitos das vagas e mostra:

- percentual de compatibilidade
- habilidades encontradas
- habilidades faltantes
- vaga mais compatível
- recomendação de estudo

## Como executar

1. Abrir o terminal na pasta do projeto
2. Rodar o comando: `node skillmatch.js`

Ou pelo navegador:

1. Abrir o Google Chrome
2. Pressionar F12
3. Abrir a aba Console
4. Colar o código e pressionar Enter

## Sobre internet e arquitetura cliente-servidor

Este projeto simula uma busca de vagas como se viessem de um servidor, usando Promise e setTimeout para representar o delay de uma requisição real. Na web, o cliente (navegador) faz uma requisição ao servidor, que responde com os dados.
